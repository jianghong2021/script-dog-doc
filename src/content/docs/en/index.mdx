### Differences from Other Script Managers

|Feature/Manager|ScriptBox|Tampermonkey|ScriptCat|
|--- |---|---|---|
|Content Scripts (extensions, enhance web pages)|✓|✓|✓|
|Sidebar Scripts (scripts run in independent windows, can be used for tools, games, long-term tasks)|✓|❌|❌|
|Independent Windows (similar to sidebar)|✓|❌|❌|
|Scheduled Scripts (scheduled long-term tasks, independent windows can replace)|❌|❌|✓|
|Visual Scripts (drag and drop to generate scripts)|✓|❌|❌|
|Visual Templates (visual and text scripts are universal)|✓|❌|❌|
|Popup Quick Launch (icon popup lists available scripts for quick launch)|✓|❌|❌|
|Third-Party Libraries (import third-party libraries for rapid script development)|✓|✓|✓|
|Resource Reference (images, styles, etc.)|✓|✓|✓|
|Tampermonkey API(Interacting with browser)|✓|✓|✓|
|Editor Extensions (rich editor and custom visual modules)|✓|❌|❌|
|Quick Start|✓|❌|❌|
|Script Backup|✓|✓|✓|
